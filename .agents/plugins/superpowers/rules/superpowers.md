# Superpowers Behavioral Guidelines

When the `superpowers` plugin is active:
1. **Check for Applicable Skills**: Before undertaking non-trivial coding tasks, check if a relevant Superpowers skill applies:
   - Architecture & Design: `brainstorming`
   - Debugging: `systematic-debugging`
   - Feature Implementation: `test-driven-development`
   - Multi-step Planning: `writing-plans` and `executing-plans`
   - Completion & Quality: `verification-before-completion`
2. **Antigravity Tool Mapping**: Follow the Antigravity guidelines in `skills/using-superpowers/references/antigravity-tools.md`:
   - Maintain task checklists as Markdown artifacts or structured plans.
   - Use standard Antigravity inspection, execution, and editing tools (`view_file`, `replace_file_content`, `run_command`).
